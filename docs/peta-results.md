# Архив результатов компактных моделей

Основное обучение исходной архитектуры описано в [original-training.md](original-training.md).

Все модели обучены на одном разбиении: 11 060 train, 3887 validation, 3576 test. Девять атрибутов, 44 выхода.

| Модель              | Лучшая эпоха | Validation macro F1 | Test accuracy | Test macro F1 |
| ------------------- | -----------: | ------------------: | ------------: | ------------: |
| ResNet18            |            4 |              0.4082 |        0.6789 |        0.4089 |
| MiniCPM: head       |            4 |              0.4806 |        0.7204 |        0.4959 |
| MiniCPM: fine-tuned |            2 |              0.5054 |        0.7277 |        0.5159 |

Каждый этап завершил пять эпох. Основная модель сначала обучала голову, затем голову и два блока энкодера. Checkpoint выбирался по validation macro F1. Итоговый тест рассчитан на CUDA с BF16.

Подробные метрики каждого класса и confusion matrix находятся в `plots/peta-*/test.json`.

Проверены ONNX бейзлайна (batch 1 и 2), HTTP MLflow Serving и видео с девятью атрибутами.

## Самостоятельная проверка

- `scripts/check_project.py`: хуки, unit tests, короткое обучение, infer, ONNX и MLflow.
- `scripts/check_peta_video.py`: YOLO, SFSORT и девять атрибутов в видео.
- `scripts/estimate_training.py`: время батча, видеопамять и место для обучения.
- `had evaluate`: подробные метрики на validation или test.

Финальная модель проверена на исходном видео: 33 кадра, 66 записей людей, все девять атрибутов. Контрольные суммы всех трёх моделей совпадают с рабочими файлами, DVC-кешем и local remote.

Обучение в MLflow заняло 1.1 минуты для ResNet, 7.4 минуты для головы MiniCPM и 8.0 минут для дообучения. Все три запуска завершены со статусом FINISHED.

Общий сценарий `scripts/check_project.py` выполнен: 55 unit tests, из них 51 пройден и четыре проверки старых весов пропущены; короткое обучение, infer, ONNX и MLflow завершились без ошибок. Старые веса отдельно проверены на CPU и CUDA.

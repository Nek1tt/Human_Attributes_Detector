## Что требует задание

В PDF два задания. Первое — выбрать и описать проект. Второе — оформить
обучение и предсказание в устанавливаемый Python-пакет.
Проект даёт 30% итоговой оценки, устный экзамен — 60%, тесты по теории — 10%.
Границы оценок: 85%, 70%, 55%.

В тексте указан учебный семестр «осень 2025», срок выбора темы — 15 октября,
срок сдачи работы — за два дня до экзамена. Даты экзамена в файле нет.

Для получения оценки должны выполняться все необходимые условия:

1. Репозиторий открыт и доступен по переданной преподавателю ссылке.
2. Сдаваемый код находится в `main` или `master`. Другие ветки не проверяются.
3. Тема соответствует описанию из первого задания.
4. Все разделы со звёздочкой реализованы хотя бы в базовом виде.

Проверяющий клонирует репозиторий, создаёт чистое окружение, устанавливает
зависимости, выполняет `pre-commit install`, `pre-commit run -a`,
запускает обучение и предсказание. Поэтому наличие файлов недостаточно:
команды должны работать последовательно на новом компьютере.

### Данные и обработка

Используется официальный архив PETA, URL и SHA256 закреплены в конфиге.
Часть i-LID исключена из-за отдельного разрешения на её использование.
Остаются 18 523 изображения. ID из разметки делятся внутри поддатасетов:
5145 ID для train, 1717 для validation и 1717 для test, seed 42.
Количество изображений: 11 060, 3887 и 3576 соответственно.

Сохранены девять атрибутов: пол, возрастная группа, головной убор,
цвет и тип верха и низа, рюкзак и сумка. Выходы по атрибутам:
3, 6, 3, 12, 12, 6, 5, 3, 3; всего 53, включая «не определен» каждого атрибута.
Классы и точное преобразование исходных меток описаны в `peta_data.py`.
Пропущенные и противоречивые категориальные метки переводятся в класс «не определен».

Бейзлайн принимает RGB 224×224 с нормализацией ImageNet.
MiniCPM обрабатывает исходный кроп своим процессором. VPM и Resampler
совпадают с исходной ревизией MiniCPM-o 2.6 INT4. Их выходы 64×3584
сохраняются в BF16 без потери битов исходных эмбеддингов.

### Модель и обучение

Бейзлайн — девять независимых ResNet50. Каждый классификатор имеет слои
2048 → 1024 → 512 → число классов. Обучаются все девять сетей.

Основная модель — исходный VisionAttrTransformer: 3584 → 768,
шесть слоёв, 12 голов внимания, CLS-токен, attention pooling,
девять отдельных классификаторов. Обучение идёт на сохранённых MiniCPM-эмбеддингах.
Неиспользуемые языковые и аудиовеса не загружаются.

Ошибка — сумма CrossEntropy по девяти атрибутам, оптимизатор AdamW.
Эксперименты изменяют learning rate и взвешивание ошибки.
Как в DOCX, лучший checkpoint выбирается по validation accuracy.
На тесте рассчитываются общая accuracy, precision, recall и F1 каждого класса.
Тест не используется для выбора эксперимента.

### Хранение

Git хранит код, конфиги, DVC-указатели и учебные графики с логами.
Фотографии, разметка, checkpoint, ONNX и TensorRT engine в Git не попадают.
Локальное хранилище DVC находится в `.dvc-storage`, кеш — в `.dvc/cache`.
На новом компьютере `download_data()` восстанавливает локальное хранилище
из открытых URL. Свой checkpoint нужно передать отдельно с DVC-хранилищем
или получить повторным обучением.

## Дополнительные баллы

Эти разделы не помечены звёздочкой.

| Критерий                | Баллы по PDF | Реализация                                                          |
| ----------------------- | ------------ | ------------------------------------------------------------------- |
| ONNX                    | 5            | `had export`, проверка совпадения с PyTorch для batch 1 и 2         |
| TensorRT                | 5            | `had tensorrt`, вызов NVIDIA `trtexec`; нужен TensorRT и NVIDIA GPU |
| MLflow Serving          | До 5         | `had package`, стандартный сервер MLflow, клиент запроса            |
| Triton Inference Server | До 10        | `had triton`, model repository с ONNX, конфиг и HTTP-клиент         |

В PDF написано «Trion», по контексту имеется в виду NVIDIA Triton.
Два сервера предлагаются как альтернативы, складывать их баллы не следует.
ResNet экспортируется целиком. ONNX исходного Transformer принимает готовые
эмбеддинги 64×3584. MLflow-пакет MiniCPM выполняет извлечение признаков на PyTorch.
TensorRT экспортируется без калибровочных данных, поэтому отдельный
калибровочный набор в DVC не требуется.

# Обучение исходных архитектур

Используются девять независимых ResNet50 и исходный VisionAttrTransformer.
Слои классификаторов совпадают с кодом первоначального проекта.
Новые списки классов содержат 53 выхода, включая «не определен» для каждого атрибута.

## Размерности

| Атрибут       | Старые классы | Классы PETA |
| ------------- | ------------: | ----------: |
| Пол           |             3 |           3 |
| Возраст       |             6 |           6 |
| Головной убор |             7 |           3 |
| Цвет верха    |            13 |          12 |
| Цвет низа     |            13 |          12 |
| Тип верха     |             8 |           6 |
| Тип низа      |             4 |           5 |
| Рюкзак        |             3 |           3 |
| Сумка         |             3 |           3 |
| Всего         |            60 |          53 |

Возрастные интервалы и виды одежды взяты из новой разметки.
Вход MiniCPM → Transformer сохранён: 64 токена по 3584 признака.
Проекция 3584 → 768, шесть слоёв и 12 голов внимания сохранены.
У каждого ResNet50 прежние промежуточные слои 2048 → 1024 → 512.

## Подготовка

Команды Setup и запуск MLflow приведены в README.

```bash
had download
had original-download
had original-extract
```

Исходные визуальные компоненты MiniCPM INT4 скачиваются из ревизии
`f347c848dd57a5dfdf5b6e32eb257101a6a8a07f`.
VPM и Resampler работают с исходными весами BF16; INT4 относится к языковой части.
Языковая и аудиочасти не вызываются для визуальных эмбеддингов и не скачиваются.
Извлечение совпадает с `MiniCPMO.get_vllm_embedding`.

Один кроп PETA даёт 64 токена по 3584 признака. Они сохраняются в BF16 без потери
битов исходного результата. `tokens.npy` читается через memory mapping,
полный массив в оперативную память не загружается.
После прерывания обработка продолжается с последнего сохранённого батча.

## Эксперименты

```bash
python scripts/train_original.py --skip-extraction --epochs 4
```

Для старых весов передайте `--resnet-weights` и `--transformer-weights`.
Они сохраняются в DVC без состояний оптимизатора. Общие классы переносятся по названиям, новые выходы инициализируются случайно.
Остальные веса переносятся из старых моделей.
Без старых весов ResNet инициализируется ImageNet, Transformer — случайными весами.

| Модель               | Вариант  | LR основных слоёв | LR классификаторов | Ошибка        |
| -------------------- | -------- | ----------------: | -----------------: | ------------- |
| Девять ResNet50      | standard |           0.00001 |             0.0003 | Обычная CE    |
| Девять ResNet50      | balanced |          0.000003 |             0.0001 | Взвешенная CE |
| Исходный Transformer | standard |           0.00005 |             0.0003 | Обычная CE    |
| Исходный Transformer | balanced |           0.00001 |             0.0001 | Взвешенная CE |

Затем лучший Transformer дообучается ещё до четырёх эпох: LR основных слоёв
0.000002, LR классификаторов 0.00005, обычная CE. Этот вариант называется refined.

Веса классов вычисляются только по train как обратный квадратный корень частоты.
Все варианты используют одинаковое разбиение. Суммируются ошибки девяти атрибутов.
AdamW, BF16, gradient clipping 1.0. Лучшая модель выбирается по validation accuracy.
Early stopping останавливает запуск после двух эпох без улучшения.

Сохраняются лучшие веса каждой архитектуры. Остальные checkpoint удаляются после
сравнения, журналы и графики всех экспериментов остаются в `plots/`.

## Место и память

Визуальные компоненты занимают около 1 ГБ. Эмбеддинги PETA — около 8 ГиБ,
с копиями DVC — около 24 ГиБ. До извлечения проверяется место для всех копий
и резерв 8 ГиБ. До обучения проверяется запас для checkpoint и DVC.
ResNet и Transformer обучаются последовательно. Крупные модели и проверки
не запускаются одновременно на машине с 16 ГБ оперативной памяти.

На PETA используются готовые кропы людей. Детектор YOLO не переобучается.

Для повторного выполнения завершённых экспериментов используйте `--restart`.

## Предсказание и экспорт

- ONNX проходит проверку структуры.
- Выходы ONNX и PyTorch совпадают с допуском `rtol=1e-3`, `atol=1e-4` для batch 1 и 2.
- MLflow Serving принимает HTTP-запрос с реальной фотографией.
- HTTP-предсказание совпадает с прямым вызовом модели.
- Новый backend возвращает девять ключей существующего видеопайплайна.

## Новая архитектура MiniCPM

Обучена Transformer-голова поверх визуального энкодера MiniCPM-o 2.6.
Пять эпох, BF16, RTX 4060 Ti 16 ГБ. Лучший validation macro F1 — 0.6139,
accuracy соответствующей модели — 0.8216. Веса: `models/minicpm_vision_head.pt`.
Графики: `plots/minicpm-head/training/version_0/`.

Новый ONNX проверен для batch 1 и 2. Файл удалён после проверки для экономии места,
его можно создать повторно командой экспорта.

Второй этап завершён: дообучены два блока энкодера, validation macro F1 — 0.6293,
accuracy — 0.8171. Веса: `models/minicpm_vision_finetuned.pt`.
Подробные результаты: [minicpm-results.md](minicpm-results.md).

Модульные тесты после изменения архитектуры: 52, ошибок нет, четыре пропуска.

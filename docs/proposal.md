# Human Attributes Detector: распознавание внешних атрибутов людей на видео

Никита Абрамов

## Постановка задачи

Система обнаруживает людей на видео, отслеживает их между кадрами и определяет девять внешних атрибутов: пол, возрастную группу, головной убор, цвет и тип верхней и нижней одежды, наличие рюкзака и сумки. Код находится в [репозитории проекта](https://github.com/Nek1tt/Human_Attributes_Detector).

### Формат входных и выходных данных

Видеосервис принимает видеофайл и возвращает MP4 с рамками и подписями и JSONL с временем, track_id, координатами, уверенностью детектора и девятью атрибутами. Классификатор также принимает RGB-кроп одного человека. Набор атрибутов одинаков для обучения, предсказания на кропах и видео.

### Метрики

При обучении записываются CrossEntropy, accuracy и macro F1. Ошибка усредняется по известным атрибутам, macro F1 - по классам каждого атрибута, затем по атрибутам. Для каждого класса рассчитываются precision, recall, F1 и support. Пропущенные и противоречивые метки исключаются. Метрики, параметры и Git commit сохраняются в [MLflow](https://mlflow.org/docs/latest/), графики и журналы - в plots.

### Валидация

PETA разделяется по ID людей внутри каждого поддатасета: 60% train, 20% validation, 20% test, seed 42. Изображения одного ID находятся в одной части. Лучшая модель выбирается по validation macro F1. Тестовая часть используется для итоговой оценки.

### Данные

Используется [PETA](https://mmlab.ie.cuhk.edu.hk/projects/PETA.html), содержащий кропы людей и разметку внешности. Поддатасет i-LID исключён, поскольку для него требуется отдельное разрешение. Остаются 18 523 изображения: 11 060 train, 3887 validation и 3576 test. Данные хранятся через [DVC](https://dvc.org/doc), официальный архив проверяется по SHA256.

Девять атрибутов имеют 44 выходных класса: пол - 2, возраст - 5, головной убор - 2, цвета верха и низа - по 11, тип верха - 5, тип низа - 4, рюкзак и сумка - по 2. Возрастные группы взяты из разметки PETA. Типы верха: куртка, свитер, костюм, футболка, другая одежда. Типы низа: брюки, шорты, юбка, капри. Сумка включает сумку через плечо, пакет и чемодан. Несколько цветов или несовместимых типов одежды исключаются из категориальной разметки. Основные сложности - дисбаланс классов, перекрытия, освещение и низкое разрешение.

## Моделирование

### Бейзлайн

Предобученный [ResNet18 из torchvision](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html) и линейный классификатор. RGB-кроп масштабируется до 128×64 и нормализуется статистиками ImageNet. Обучается классификатор, энкодер заморожен. Старый ансамбль ResNet50 сохранён отдельно.

### Основная модель

Визуальный энкодер [MiniCPM-o 2.6](https://huggingface.co/openbmb/MiniCPM-o-2_6) используется без языковой и аудиочастей. Кроп 224×112 даёт 128 токенов по 1152 признака. Проекция переводит их в 256 признаков, затем работают два Transformer-слоя с четырьмя головами внимания. После усреднения токенов классификатор выдаёт 44 логита девяти атрибутов.

Обучение выполняется через [PyTorch Lightning](https://lightning.ai/docs/pytorch/stable/), оптимизатор AdamW. Сначала пять эпох обучается голова. Затем загружается лучший checkpoint и пять эпох дообучаются голова и два последних блока энкодера. Используются BF16 и batch 32. Параметры моделей, данных и обучения задаются через [Hydra](https://hydra.cc/docs/intro/).

Людей обнаруживает YOLO ONNX, сопровождение выполняет [SFSORT](https://github.com/Applied-Deep-Learning-Lab/SFSORT). Атрибуты сохраняются по track_id и используются в следующих кадрах.

## Внедрение

FastAPI-сервис принимает видео и позволяет скачать результат. Предсказание на кропах запускается командой had infer, оценка на тесте - had evaluate. ONNX и MLflow Serving используют тот же checkpoint и его разметку классов. Зависимости закреплены в uv.lock, данные и веса хранятся в DVC. Установка, обучение и самостоятельные проверки описаны в README.

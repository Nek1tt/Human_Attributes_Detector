# Определение атрибутов людей

Автор: Абрамов Никита.

## Задача

Определять внешние атрибуты человека по фотографии: пол, возрастную группу,
одежду и сумки. Для видео использовать детектор и трекер,
а классификатор запускать на кропах людей. Результат — атрибуты человека,
размеченное видео и покадровый JSONL.

## Данные

[Market-1501](https://zheng-lab-anu.github.io/Project/project_reid.html)
содержит 32 668 фотографий, 1501 человека, съёмку с шести камер.
[Разметка атрибутов](https://github.com/vana77/Market-1501_Attribute)
содержит сведения о поле, возрасте, одежде и аксессуарах.
Обучающая часть — 751 человек, тестовая — 750.
20% обучающих людей выделяется в validation.
Фотографии одного человека остаются в одной части.

Вход переводится в RGB, масштабируется до 128×64 и нормализуется.
При обучении применяется случайное горизонтальное отражение.
Неуказанный цвет исключается из ошибки и метрик.
Данные сохраняются в [DVC](https://dvc.org/doc).

## Модель

Используется предобученный
[ResNet18 из torchvision](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html).
Последний слой заменён классификатором 12 атрибутов:
пол, возрастная группа, длина волос и рукавов, длина и тип нижней одежды,
головной убор, рюкзак, сумка, дамская сумка, цвет верха и низа.
Выход — 39 логитов. По умолчанию обучается только последний слой.
Это позволяет обучать модель на CPU. Обучение всей сети включается конфигом.

Обучение выполняет [Lightning](https://lightning.ai/docs/pytorch/stable/),
настройки хранятся в [Hydra](https://hydra.cc/docs/intro/).
Для видео используются YOLO ONNX и
[SFSORT](https://github.com/Applied-Deep-Learning-Lab/SFSORT).

## Метрики

CrossEntropy усредняется по атрибутам с известными метками.
Accuracy — доля верных меток. Macro F1 усредняется по классам каждого
атрибута, затем по атрибутам. Лучший checkpoint выбирается по validation
macro F1. Тестовые люди не участвуют в выборе checkpoint.

[MLflow](https://mlflow.org/docs/latest/) сохраняет метрики,
гиперпараметры и Git commit. В репозитории сохраняются графики
loss, accuracy и macro F1, а также журнал обучения.

## Этапы работы

1. Скачать фотографии и разметку, сохранить через DVC.
2. Подготовить метки и разделить людей на train, validation и test.
3. Обучить классификатор, записать эксперимент в MLflow.
4. Сохранить лучший checkpoint с обработкой изображения.
5. Выполнить предсказание на новых изображениях.
6. Экспортировать ONNX и упаковать модель для MLflow Serving.
7. Подготовить команды для TensorRT и Triton.

Код и команды запуска — в
[репозитории проекта](https://github.com/Nek1tt/Human_Attributes_Detector).
